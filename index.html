🧠 Human Brain Connectomics Database

Structural (DTI) and Functional (fMRI) Connectivity Repository

📄 About This Dataset

This repository provides a comprehensive collection of databases on human brain connectomics, covering both structural connectivity (DTI, tractography) and functional connectivity (fMRI, resting-state). It includes brain network maps, graph-theoretic metrics, and analyses of inter-individual variability.
